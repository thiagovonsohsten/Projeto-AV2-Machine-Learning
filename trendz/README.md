# Dashboards Exportados

Esta pasta contém dashboards exportados do ThingsBoard ou Trendz Analytics.

## Como Exportar Dashboard

1. Acesse o ThingsBoard em http://localhost:8080
2. Crie seus dashboards e widgets
3. Exporte a configuração do dashboard
4. Salve o arquivo JSON nesta pasta

## Dashboard Streamlit

O dashboard principal está implementado em `../dashboard/app.py` e é acessível em:
- **URL**: http://localhost:8501
- **Tipo**: Streamlit (mais leve e fácil de usar)

O dashboard Streamlit já está funcional e não requer exportação manual.
